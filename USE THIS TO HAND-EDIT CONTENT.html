Edit your website

Click any text on your site and type over it, then save your changes straight back to the files — no coding.

  1. Click the button below and choose your “Working Version” folder.
  2. When Chrome asks, choose View files, then Save changes to allow editing.
  3. Pick a page, click any text, and type. Hit Save when you’re done with a page.

Edit Website Editing:
Click any text to edit it (editable areas highlight on hover). Menus, headers, and footers are locked — they repeat across pages, so ask Claude to change those. Link text can be edited; the destination it points to cannot. Press Save changes before switching pages. Only the exact text you change is written; everything else stays untouched.
